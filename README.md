# Verilog Truth Table Generator

A Verilog project that implements multiple Boolean functions using **sum-of-minterms expressions** and automatically generates their complete truth table using an iVerilog testbench.

This project was created for a Digital Logic course to demonstrate how Boolean functions can be represented in Verilog and tested across every possible combination of four binary inputs.

## Project Information

- **Language:** Verilog
- **Simulator:** iVerilog
- **Editor:** Visual Studio Code
